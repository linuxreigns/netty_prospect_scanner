# CORE_PRINCIPLES.md — NETTY SALES ENGINE

## 1) Identidad del sistema
**Netty** es el producto principal (asistente inteligente de ventas, soporte y automatización).

**NETTY SALES ENGINE** es el ecosistema autónomo diseñado para vender Netty.
No sustituye a Netty; lo potencia comercialmente.

## 2) Principio crítico (no negociable)
Todo prospecto debe entender explícitamente que fue:
- descubierto,
- analizado,
- auditado,
- clasificado,
- contactado,
- y seguido

por el ecosistema IA que impulsa Netty.

Este principio debe verse en:
- dashboard,
- auditorías,
- propuestas,
- correos,
- seguimiento,
- branding,
- prompts,
- analytics.

## 3) Objetivo operativo del MVP
1. Descubrimiento autónomo de prospectos.
2. Validación de negocios de Panamá.
3. Fingerprinting tecnológico.
4. Website audit.
5. Netty Fit Score.
6. Dashboard operativo tipo centro de mando.
7. Exportación CSV/XLSX.
8. Alertas HOT.
9. Auditorías IA.
10. Propuestas automáticas (con aprobación humana para envío).

## 4) Filosofía de arquitectura
Construir:
- módulos desacoplados,
- workers/servicios independientes,
- persistencia confiable,
- trazabilidad completa,
- operación 24/7.

Evitar:
- monolito rígido,
- scripts ad-hoc sin estructura,
- scraping agresivo o destructivo.

## 5) Agentes obligatorios
1. Prospect Discovery Agent
2. Panama Validation Agent
3. Technology Fingerprint Agent
4. Website Audit Agent
5. Commercial Qualification Agent
6. Netty Solution Architect Agent
7. Proposal Generator Agent
8. Outreach Agent
9. Follow-Up Agent
10. CRM Intelligence Agent

## 6) Reglas comerciales de comunicación
Toda salida comercial debe reforzar:
- “Este análisis fue generado automáticamente por NETTY SALES ENGINE”.
- “Netty ya está demostrando en la práctica las capacidades que ofrece”.

## 7) Límites de implementación MVP
No implementar aún:
- WhatsApp API real,
- envío masivo agresivo,
- scraping destructivo,
- Playwright masivo,
- clustering complejo,
- IA local pesada.

## 8) Prioridad absoluta
**Sistema funcional, modular y estable**.
Primero estabilizar pipeline y operación; luego profundizar automatización.
